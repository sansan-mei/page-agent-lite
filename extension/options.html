01 / CONNECTION

连接你的模型

高级

以 reasoning_effort 发送，可能增加耗时和费用；接口不支持时选「服务默认」。

自动模式在原生工具调用失败时改用 JSON 文本；重新保存会再次尝试原生。

仅限 HTTPS 或本机 HTTP 地址；密钥只存本机、不同步，不交给网页。

网站访问权限

也可在侧栏只授权当前网站；助手只在你开始或继续任务时操作网页。

02 / BEHAVIOR

执行预算

每轮调用一次模型，翻页后继续累计。

补充指令总长上限取 12000 与单次上限 6 倍中的较大值。

高级

填写模型实际支持的上下文窗口；预留 2000 token 输出，用量达到阈值后压缩历史。接口未返回用量时按估算。

保存模型连接与执行预算，并授权 API 地址。

03 / SITE & MEMORY

网站与记忆管理

选择已打开的网页。修改或清空记忆会取消相关旧请求并暂停相关任务，请返回侧栏继续。

网站长期记忆

仅在本机保存，同一网站跨标签页和浏览器重启可用。模型按需维护；不会自动保存整段对话。切换登录账号时请检查笔记是否适用。

全局长期记忆

保存跨网站适用的偏好和通用经验，仅限本机，跨标签页和浏览器重启可用。可查看、编辑或新增笔记；修改会暂停各网站相关任务。网站专用流程请保存在网站记忆中。

临时记忆

模型自行判断保存、读取和清理。记忆仅限当前标签页和网站，关闭标签页后清除；你也可以随时清空。

04 / APPEARANCE

侧栏主图

自动保存

新对话中显示的图片；选择后立即保存，已打开的侧栏同步更新。

PNG / JPG / WebP，不超过 5 MB；最长边缩至 1024 px，只存本机、不发给模型。

05 / SCRIPTS

脚本执行

未开启

普通工具做不到时，助手可以编写 JavaScript 在当前网页运行（run_script）。每次运行前侧栏显示完整代码、目标网站和运行环境，须你批准才执行这一次；返回值会发送至你配置的模型服务。

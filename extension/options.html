01 / CONNECTION

连接你的模型

仅允许 HTTPS 或 localhost / 127.0.0.1 / [::1] 的 HTTP 地址。密钥仅保存于本机 chrome.storage.local，不同步，也不交给网页内容脚本；本机存储并非加密保险箱。

02 / BEHAVIOR

选择执行方式

不限轮数时，持续执行直到任务完成、需要确认、发生错误或你点击停止。也可以填写 100、500 等自定义上限。每轮会调用模型，翻页后累计轮数继续保留。

请填写模型实际支持的上下文窗口，默认 32768 token；预留 2000 token 输出空间，在剩余预算的 80% 才压缩。接口未提供用量时采用估算。正常执行保留原始历史以利于缓存复用，缓存是否命中由服务商决定。

自动点击默认关闭；开启后模型提出的点击会直接执行，包括页面上的提交、删除等按钮。自动填写独立控制填写、勾选和下拉选择。保存后对新任务或点击「继续任务」的任务生效。停止会取消未完成的模型请求，已发出的网页操作不会自动撤销。

03 / ARTICLE TOOLS

文章工具的站点设置

未启用时，工具栏点击授予当前站点临时访问。启用后会在该站点自动恢复保存的文章修改；文章工具可从侧边栏打开。文章恢复不会调用模型；后台未完成任务会继续运行。授权后请刷新网页。

已启用站点

    停用会取消自动注入和恢复；已有网页请刷新。停用不删除已保存记录，重新启用会恢复。清除记录请在对应网页点击「当前页全部撤销/清除保存」。浏览器扩展详情可单独撤回授权；API 与网页可能共用同一源，因此停用不会自动撤回源权限。

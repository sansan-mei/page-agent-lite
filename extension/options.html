01 / CONNECTION

连接你的模型

通过 reasoning_effort 请求模型思考强度；效果由模型服务决定。若接口不支持，请选择服务默认。思考可能增加耗时和费用。

仅允许 HTTPS 或 localhost / 127.0.0.1 / [::1] 的 HTTP 地址。密钥仅保存于本机 chrome.storage.local，不同步，也不交给网页内容脚本；本机存储并非加密保险箱。

02 / BEHAVIOR

执行预算

不限轮数时，持续执行直到任务完成、任务暂停、发生错误或你点击停止。也可以填写 100、500 等自定义上限。每轮会调用模型，翻页后累计轮数继续保留。

请填写模型实际支持的上下文窗口，默认 100000 token；预留 2000 token 输出空间，在剩余预算的 80% 才压缩。接口未提供用量时采用估算。正常执行保留原始历史以利于缓存复用，缓存是否命中由服务商决定。

填写、勾选、选择和点击均自动执行，无需开启开关或逐次确认。你可以随时停止；已发出的网页操作不会自动撤销。

03 / SITE & MEMORY

网站与记忆管理

选择已打开的网页。修改或清空记忆会取消相关旧请求并暂停相关任务，请返回侧栏继续。

网站长期记忆

仅在本机保存，同一网站跨标签页和浏览器重启可用。模型按需维护；不会自动保存整段对话。切换登录账号时请检查笔记是否适用。

临时记忆

模型自行判断保存、读取和清理。记忆仅限当前标签页和网站，关闭标签页后清除；你也可以随时清空。

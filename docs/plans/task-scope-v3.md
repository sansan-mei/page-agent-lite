# 多成员任务设计（PA8 剩余部分）

状态：设计，未实现。已实现的单成员部分（V3 根记录、归属索引、发布协议、任务级调度、站点范围、跨来源切换、单成员关闭）见 [存储](../storage.md) 和 [运行器](../agent-runtime.md)，本文只写剩余目标。

## 原则

- 执行须同时满足：浏览器主机权限 + 用户给任务的站点/成员授权。全站权限不会把任何标签交给模型。
- 一个标签最多属于一个未结束任务。被占用时拒绝加入，不抢占、不合并、不停止其他任务。
- 停止、我来操作、继续、结束作用于整个任务；侧栏显示当前执行标签和授权站点。用户手动切到别的标签不会让任务跟过去。
- 执行目标切换（activeTabId）与浏览器前台激活分开，默认不抢前台。
- 不按 URL 或标题猜测标签归属；tabRef 只能取自刚读到的任务目录，不接受任意 tabId。

## 目标数据模型

在现有 `taskRoot` 上扩展：

| 字段 | 目标 |
|---|---|
| members | `{tabId, tabRef, kind: initial / user_joined / task_created, joinRevision}`，不存 DOM ID |
| activeTabId | 当前执行标签；每次向浏览器核实 URL 和 origin |
| pending / check | 增加 activeTabId，旧 expected 不能在其他标签上求值 |
| taskRegistry | `tabOwners`（tabId → taskId）为唯一权威，不含目标、正文或笔记 |

成员变更沿用现有三步发布协议（意图 → 根 → binding），全局短串行队列处理归属变更，不在队列中等待模型或网络。registry 与 root 修订不一致时暂停修复，不“挑看起来新的”执行。

## 计划中的工具

沿用严格 JSON / V2 结果；实现时同步注册表和 [网页工具](../browser-tools.md)。

| 工具 | 约束 |
|---|---|
| task_tabs | 只列本任务仍存在的成员：tabRef、当前站点、有限标题；不列无关标签 |
| tab_switch | 只能切到已加入成员；取消旧请求和等待、轮换 token 与 scopeRevision、清旧读取范围后重新观察；不重置轮数 |
| tab_open | 只能打开授权 origin 的明确 URL；先记创建意图，用浏览器返回的 tabId 登记为 task_created。回执丢失则暂停请用户核对，不按 URL 认领 |
| tab_close | 只能关闭仍属本任务的 task_created 标签；关闭活动标签前须先切到另一成员，否则暂停。有未确定副作用时不自动关闭 |

加入已有标签由用户在范围面板中选择并确认，展示站点、类型、是否被其他任务占用；不把全浏览器标签列表发给模型。移除成员不关闭网页。

## 事件处理

| 事件 | 处理 |
|---|---|
| 非活动成员关闭 | 只移除该成员，任务继续 |
| 活动成员关闭、仍有其他成员 | 取消请求、暂停，请用户选择后重新观察 |
| 最后一个成员关闭 | 现有行为：ended/`member_closed` |
| 切换时旧请求/等待迟到 | token/scopeRevision 拒绝，旧 ID 不落到新文档 |
| tabs.create / update / remove 回执丢失 | 只读对账或暂停，最多执行一次 |
| 归属写入中途 worker 终止 | 启动对账到暂停，不出现多重归属，不重置预算 |
| task_created 标签被用户导航到未授权来源 | 保留所有权标记，但不可操作、不自动关闭 |

## 实施顺序

1. 用户加入已有标签、任务成员目录（侧栏 + 存储）。
2. `tab_switch` 与多成员关闭分支。
3. `tab_open` / `tab_close` 及丢回执对账。

每步独立实现、测试、提交；未通过边界测试的工具不写成已实现。

## 验收要点

- 全站权限但任务只有 A：B 的内容不读取、不注入、不扩大范围。
- 两个独立任务互相抢标签：拒绝，对方状态和预算不变。
- 同 URL 的用户标签与任务创建标签：只认已登记 tabRef，不关闭用户标签。
- 源站旧笔记/摘要含 fixture 私密标记：新标签/新来源的模型输入中不出现。
- 配额失败与迁移失败：保留原记录和未确定检查点，不出现两个运行任务。

测试分层：Node 假时钟与存储故障注入 → 真实 MV3 + 本机 stub（双 origin 服务、可计数的标签操作、worker 故障注入）→ 原生授权手势与真实模型人工任务。

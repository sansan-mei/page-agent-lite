# 使用指南

安装步骤见 [README](../README.md#快速开始)。本文按界面说明行为与限制。

## 安装与更新

- 需要 Chrome / Edge 120+，且支持 `storage.local` 访问隔离 API；缺少时扩展拒绝初始化。
- 更新源码后在扩展管理页重新加载，并刷新已打开的网页；新增权限时浏览器可能要求重新启用。
- 已有配置、记忆和设置在更新后保留；旧版会话中的任务会迁移为暂停状态，点击「继续任务」即可。
- 若扩展错误页出现 `importScripts ... core.js failed to load`，是扩展文件未完整加载，与网站授权或密钥无关：确认加载的是完整 `extension/` 目录，重新加载扩展并刷新网页。不要用开放全站权限来解决。

## 设置页

右键扩展图标选「选项」，或侧栏点「设置」。

默认只显示「连接模型」卡片（API 地址、模型 ID、密钥）和紧凑的「脚本执行」「真实输入与截图」状态行；没有编号导航、常驻说明或固定保存栏。

| 入口 | 内容 |
|---|---|
| 连接模型 | 接口格式（OpenAI 兼容 / Claude）、API 基础地址（如 `https://api.openai.com/v1` 或 `https://api.anthropic.com/v1`，不加 `/chat/completions` / `/messages`；HTTP 仅限 localhost / 127.0.0.1 / [::1]）、模型 ID、密钥（本机无鉴权服务可留空）；密钥只存本机、不同步，不交给网页 |
| 脚本执行 | 未授权时显示「允许」，授权后引导打开浏览器开关，开启后显示「已开启」和「关闭」；见 [脚本执行](#脚本执行) |
| 真实输入与截图 | 默认关闭（含升级的老用户）；「开启」/「关闭」只改本机设置，不弹浏览器权限框。关闭时助手不截图、不按截图位置点击、不发真实鼠标输入，正在使用的调试连接立即断开；附图照常识别。开启后每次使用仍需在侧栏批准，见 [限制](#限制) |
| 更多设置（默认折叠） | 回复语言；执行预算：轮数上限（默认 100，0 不限，每次模型请求计一轮、翻页后继续累计）、单条消息字符上限（默认 2000，范围 100–10000）；高级：思考强度、工具协议、上下文窗口（默认 100000，范围 8192–262144）、压缩阈值（默认 80%，范围 50–95%）；网站访问授权；侧栏主图选择与恢复；识别模型（可选：模型、接口格式、API 地址、密钥；模型留空用主模型，地址留空沿用主模型地址和密钥），用于不能看图的模型 |
| 管理记忆（默认折叠） | 选择已打开网页后管理其网站长期记忆；管理全局长期记忆；查看或删除技能（所有网站共用） |

- 「测试连接」先保存，再用当前模型发一次带 16×16 小图的请求：成功显示「支持看图」；接口以图片类错误（HTTP 400）拒绝显示「不支持看图」；其他错误照常报错，看图能力记为未知。结果按模型记住，重新保存设置后清空。
- 连接卡片与「更多设置」内的「保存」执行同一操作：一次保存模型连接、回复语言与执行预算，并申请 API 地址的访问授权。结果或错误只在本次点击的按钮旁显示。主图、记忆和网站授权操作即时生效，不需要点保存。
- 保存不代表连接已验证。只支持非流式请求：OpenAI 兼容格式走 Chat Completions（`Authorization: Bearer`），Claude 格式走 Anthropic Messages（`x-api-key`，系统指令带缓存标记，重复请求更省）。
- 默认回复语言：可选跟随浏览器（按浏览器界面语言解析，如 English、简体中文）、简体中文、English、繁體中文、日本語，或「其他…」后自行填写；保存的是语言名称文本，已保存的值不在预设中时显示为「其他…」并预填。
- 思考强度：低/中/高（默认中）通过 `reasoning_effort` 发送；不支持该参数的服务选「服务默认」。Claude 格式不发送思考参数，固定输出上限 4096。显式思考时不发送 temperature 和输出上限，可能更慢更贵，仍受 60 秒请求超时限制。
- 工具调用协议：自动（默认）先用原生工具调用（`tools`），模型偶尔直接回 JSON 文本时本轮照常使用；接口拒绝工具调用或模型回非 JSON 文本时，该模型改用严格 JSON 文本，这一轮不执行任何操作、计一轮；重新保存 API 设置会再次尝试原生调用。也可固定为「仅原生工具调用」或「仅 JSON 文本」。
- 主图：上传限 5 MB、边长 ≤ 8192，保存时最长边缩到 1024，保存数据 ≤ 2 MB；只存本机，不发给模型。

## 界面语言

- 界面语言跟随浏览器界面语言（`chrome.i18n`）：英文显示英文，中文及其他语言显示中文（默认语言 `zh_CN`）。扩展名称、说明、工具栏提示、侧栏、设置页、记忆管理、主图设置均已翻译。
- 限制：后台产生的消息仍为中文，包括侧栏对话中的运行状态消息（如任务暂停原因、完成/失败说明、「你：」回显）、后台与网页工具返回的错误提示、工具卡片中的回执 `message`。模型回复按「默认回复语言」输出，不受界面语言影响。

## 网页授权

- 侧栏「授权当前网站」「授权全部网页」申请浏览器主机权限；已授权的按钮自动隐藏，撤销后重新出现。也可在浏览器扩展详情的「网站访问权限」中撤回。
- 主机权限只表示扩展能访问；扩展只在你开始或继续任务时操作该任务的网页。浏览器内部页、扩展商店等无法操作。

### 跨源表单

直接嵌入页面的跨源 iframe 可读取、填写和核对。助手因框架未授权而受阻时，侧栏显示「授权嵌入式表单网站」卡片；点击对应来源的「记住授权并继续」，授予浏览器权限并记住当前网站 A→表单网站 B 的关系后重新观察当前页，不跳转或提交表单。关系按完整 origin 保存，跨新对话和浏览器重启沿用，只允许 A 内嵌 B，不授予其他网站 C 或独立 B 标签页权限。侧栏「已记住的嵌入网站授权」中可「移除并忘记授权」；撤销浏览器网站权限后也无法继续访问。旧版未保存这层关系，首次使用需再确认一次。拒绝授权会保持暂停，不反复尝试；「授权当前网站」只授权顶层网站。卡号、安全码等仍需本对话的敏感字段授权。框架应滚入视口并无遮挡；嵌套、重定向和同 URL 多框架暂不支持，特殊组件的合成输入兼容性仍有限。

测试结账页可要求「只填写测试资料，停在付款前」；助手应在最终提交前暂停，填值核对只证明网页字段状态。

## 侧栏

顶部：「历史记录」「新对话」「设置」。中间是消息与工具卡片，底部固定输入框和进度。新标签页、设置页也可发起对话；已有浏览器网站权限时直接导航，缺少权限时显示「授权网站并继续」并说明尚未打开、任务未完成。内部页不读取正文或表单，也不显示网页标题栏和常驻说明；状态区仅在有提示时出现。Enter 发送，Shift+Enter 换行，输入法选词回车不发送。

| 操作 | 行为 |
|---|---|
| 发送 | 无任务或点过「新对话」时新建任务；否则作为补充指令追加到当前对话，保留目标、任务 ID 和此前回答。任务完成后可直接继续追问或布置下一步，并开启新的轮数预算；在其他网站发送时按 [网站导航](#网站导航) 重新读取，不带旧站点内容。单次内容不超过设置的输入框字符上限；补充指令总长上限取 12000 与单次上限 6 倍中的较大值，超限拒绝而不裁剪。未完成的网页任务只能在任务当前所在站点发送 |
| 停止 | 取消模型请求并丢弃迟到结果；已发出的网页操作不撤销 |
| 继续任务 | 重新读取当前页后继续；预算耗尽或已完成后继续会开启新预算 |
| 我来操作 | 暂停自动执行，你手动修改网页后点「操作完成，重新观察」；保留任务和剩余轮数，结果不明的旧操作仍不会重复 |
| 新对话 | 结束当前任务，下一次发送新建任务；旧对话进入历史 |
| 目标模式 | 发送按钮左侧的开关。开启后核对未通过、目标失效、普通阻碍时自动重新规划更多次（见下），直到完成、停止或用完轮数；点一次开启、再点一次关闭，开关保存在本机（跨侧栏、标签页和浏览器重启），对之后所有新任务和补充指令生效；任务进行中点击会同时切换当前任务，不会自动继续已暂停的任务。开启时按钮显示为橙色。开启时如「真实输入与截图」未开，输入框上方显示一行提示，点「开启」即打开该设置；脚本执行缺浏览器开关的提示也在同一行，× 关闭，每次开启目标模式最多提示一次 |
| 图片 | 输入框下方的「+」、粘贴（Ctrl/⌘+V）或拖入：PNG/JPEG/WebP/GIF，单张原图 ≤ 5 MB，每个任务最多 4 张（含已发送的）；不支持 SVG 和网页上拖来的图片链接。图片先压缩成 JPEG（长边 ≤ 1568）显示为缩略图，可点 × 移除，随下一次发送（新任务或补充指令）提交。能看图（或未知）的模型每轮都看到全部附图；不能看图的模型由识别模型把每张图转成文字（计一轮，文字可能有误，在目标下方「附图 N 张」中查看），之后助手还可以就某张图提新问题再识别。新对话或清空后图片删除，历史只留张数和识别文字 |
| 多项选择 | 模型需要你决策时显示复选框，「提交选择并继续」只传回选择，随后重新读取页面 |

- 工具卡片可展开查看动作参数和扩展回执（不是原始 API 请求）。切换网站后，侧栏保留此前站点的消息与工具记录供查看；旧站点内容仍不进入新站点的模型请求。状态区分「已派发，待核对」「已滚动」「已到边界」「目标过期/被遮挡，未执行」「结果未知」等。
- 「任务计划」折叠区显示模型维护的子目标。「曾核对通过」只代表当时页面状态，不代表任务完成。
- 侧栏打开期间切换浏览器标签页会保留当前对话；点顶部「切换标签」才切换侧栏目标，不停止原任务。网页动作仍只在任务执行标签页进行。
- 关闭侧栏任务仍运行；关闭浏览器则停止。后台休眠后由浏览器事件和 alarm 唤醒，可能有延迟。
- 任务执行期间主页面常驻蓝色虚拟指针，等待模型回复和滚动时也保留；只读观察和预期核对保留箭头位置；执行动作时箭头平滑滑向操作目标，目标边框与点击圆环短暂显示；系统开启「减少动态效果」时直接定位。停止、暂停、完成或「我来操作」后隐藏。它只是视觉反馈，不移动系统鼠标。

### 历史记录

- 列出所有网站的对话（最近 50 条，标题、网站、状态、更新时间），保存在本机，浏览器重启后仍在；点击只读查看消息、工具结果和摘要，查看不会恢复任务或发给模型。
- 重启前未结束的对话显示「已中断」，不能继续。已授权敏感字段的值在历史中显示为「已隐藏」。
- 每条右上角的垃圾桶图标可删除；运行、等待或暂停中的对话需先停止。
- 「运行详情」显示任务 ID、观察/操作/核对计数、上下文用量、缓存命中、请求与工具耗时，以及当前任务摘要。
- 「导出当前任务统计（不含正文）」下载 JSON：只有状态、轮数、计数、耗时和动作/状态分布，不含目标、URL、网页文字、笔记或令牌；不能导入恢复。
- 「清空当前对话记录」停止并删除当前任务，其他历史保留。
- 关闭任务的最后一个标签页会把任务结束并归档（已发出的操作不撤销），之后仍可在历史中查看。

### 网站导航

助手按任务需要直接导航，仅缺少浏览器网站权限时请求授权；不再逐站申请任务授权。

- 助手可按任务需要单标签导航。切换来源后重新读取页面，只带上你的原目标和补充指令，不带旧站点的表单值、笔记正文或摘要；轮数累计不重置。结果不明的旧操作仍须核对或暂停，不重放。

### 任务标签页

「任务标签页」中点「查看与加入标签页」：

- 列出任务标签页（tab0 为初始标签页，「执行中」为助手当前读写的那个）和已打开的普通网页；被其他任务占用的不可选，站点不在任务范围的会标注。
- 「加入任务」后该标签页归本任务，其他任务不能使用；每个任务最多 8 个。
- 「移出」只解除归属，不关闭或改动网页；执行中的标签页不能移出。加入和移出不会暂停任务。
- 助手默认能看到其他已打开普通网页的标题和网站（最多 20 个，被其他任务占用的不列出），看不到正文。需要读取其中一个时，侧栏显示「允许助手读取这个标签页？」：「允许读取」后该页以「用户加入」身份加入任务并成为执行标签页；「不允许」则不读取，助手改用其他方式。确认前点「继续」无效；停止、接管或发送补充指令会让该请求失效。
- 助手一次只在一个执行标签页读取和操作。它可以切换到任务里的其他标签页、在后台打开新标签页（需该网站已授权浏览器权限），并关闭它自己打开的标签页；不会切换浏览器前台，不会关闭你加入的标签页，也不会关闭被你导航到其他网站的标签页。切到其他网站时与单标签导航一样重新读取、不带旧站点页面内容，但助手可以写一段交接笔记（最多 2000 字，如要搬运的数值、对比结论）带过去，并能看到自己切换过哪些标签页。连续切换 6 次标签页而没有任何网页操作（目标模式 10 次）会暂停，避免来回切换不停；点继续或发送补充指令后重新计数。
- 在任务的任一标签页打开侧栏都能看到并停止、接管、继续该任务；发送的内容作为补充指令。任务结束后，在非执行标签页发送会把它从旧任务释放并新建任务。
- 关闭成员标签页会自动移出，任务继续；关闭执行中的标签页时，若还有其他打开的任务标签页，任务暂停在其中一个，点继续后重新读取，进行中的操作按结果未知处理、不重放；没有其他标签页则结束任务并释放全部成员。
- 新标签页打开时若浏览器未返回结果或后台中断，任务暂停，请你检查标签栏后继续；助手不会重复打开，也不会按网址认领。

## 助手能做的操作

- 读取：顶层 DOM 文字、表单字段、交互元素与页面区域；长正文、控件、区域都可分段读取或按名称查找。
- 操作：填写、勾选、选择、点击、悬停、窗口/容器滚动、滚轮、按键（方向键、Enter、Escape、Tab 等及修饰键组合）、双击、右键；简单纯文本 contenteditable。
- 批量填写：已知多个字段的值时，模型可以一轮给出 2–8 项填写/勾选/选择，助手逐项执行并核对，后续项不再请求模型、不计轮数；某项失败、字段消失、页面跳转或你发了新消息即停，剩余项不执行，交回模型。点击和提交不批量。
- 等待：按网页条件等待（默认 10 秒，最多 30 秒），或纯延时（100–30000 毫秒，如「等待 15 秒后继续」；实际间隔会因调度和模型耗时变长）。
- 核对：字段值、勾选/选中/展开状态、区域文字、元素可见/消失、URL。模型声明完成条件时必须核实；没给时显示为「模型报告完成」。
- 操作后预期结果在期限内未核实（如编辑器改写了文字格式、目标被重新渲染、页面更新慢）时，先重新读取页面交给模型判断，最多 2 次后才暂停；助手本身不会自动重发原操作。字段值与区域文字比较时忽略空白和换行差异。
- 遇到普通阻碍时最多自动重新规划 3 次；缺少必要信息或你要求暂停时立即暂停。重要操作只提示不确认，识别靠启发式，可能遗漏。
- 目标模式：核对重新规划 5 次（含完成条件和等待条件）、目标失效 5 次、普通阻碍 3 次、连续无变化 6 次后才暂停；结果不明的点击不再被拦截，模型看到新页面效果缺失时可以重做，可能重复操作，请勿在提交、付款类任务中开启。轮数上限、脚本与截图/真实输入批准、权限和敏感字段确认不变。开启时如未授权脚本执行，会顺带弹出一次授权请求（拒绝也照常开启）；已授权但浏览器「允许用户脚本」未打开时，侧栏提示一次，可点「打开扩展详情」自行打开，关闭目标模式不会收回授权。

|---|---|---|---|
| 网站长期记忆 | 完整 origin（协议+主机+端口） | 本机 IndexedDB，跨任务/标签页/重启 | 32 条/64000 字符，单条 2000 |
| 全局长期记忆 | 所有网站 | 同上 | 同上 |
| 技能 | 所有网站共用，每个技能可标适用网站 | 同上 | 32 个/96000 字符，步骤 4000 |

- 模型每轮只看到记忆目录，按需读取正文，并自行决定写入、删除、清空；不会自动保存整段对话。是否记对、用对取决于模型。
- 任务完成后，做过网页操作或收到过补充指令的任务会自动多发一次「复盘」请求（计一轮），由模型决定是否记住偏好、纠正或已验证的网站做法；多步流程顺利完成时还会存成「技能」（适用说明 + 适用网站 + 步骤），之后遇到类似任务时模型先读取再照做：本站技能排在前面，通用技能（如翻页采集）在任何网站都可用，别的网站的技能只作参考。步骤不对会在下次复盘时改写。记住的内容在时间线显示「任务复盘：…」，可在「管理记忆」中修改或删除（技能只能删除）。在同一对话里发送新消息会取消进行中的复盘；点「新对话」不会，复盘在后台完成后直接存入「管理记忆」。
- 在设置页展开「管理记忆」后可查看、编辑、新增、删除、清空、导出（长期记忆导出 JSON；暂不支持导入或同步）。网站记忆需先选择目标网页。
- 修改或清空记忆会取消相关旧请求并暂停任务，回侧栏点继续即可；清空全局不影响网站笔记。
- 同一网站不同账号共用网站笔记。不要让它记录密码、密钥、身份信息；本机数据库没有加密。
- 记忆只是参考，当前指令和页面证据优先。

## 上下文

- 上下文窗口应填写模型实际支持的大小；预留 2000 token 输出，达到输入预算的压缩阈值后压缩历史。
- 接近上下文预算时，模型把旧过程整理为摘要（已完成及证据、待完成、关键事实与纠正、失败方法、未确定操作），保留最近至少 6 条完整结果；原始结果归档后模型可按需读取。
- 摘要请求计入轮数；失败保留原记录并暂停。压缩后仍超阈值也会暂停，避免反复付费。
- 用量优先使用接口返回的 token 数，否则估算；不是精确 tokenizer，也不保证缓存命中。

## 敏感字段授权

模型判断任务需要密码、验证码、卡号或安全码等字段时，会在侧栏对话区请求确认。默认屏蔽；点击「授权本次对话」后重新观察并继续，授权只属于当前对话，新对话需重新确认。「不授权」保留屏蔽并暂停，可补充指令处理普通字段。授权不扩大任务目标，不代表同意订阅或付款。

授权字段的内容可能发送至自选模型服务，并出现在本次浏览器会话的任务记录中。文件和隐藏字段始终排除。

## 脚本执行

普通工具做不到时（如读取网页 JS 状态、批量提取），助手可以编写 JavaScript 在当前网页运行（`run_script`）。默认关闭。

开启后还能处理普通工具不支持的：开放式 Shadow DOM；嵌套、跳转过或同 URL 的同源 iframe；原生 confirm/alert（在 MAIN 环境预先改写）；简单富文本（contenteditable）、HTML5 拖拽、长按、网页自己实现的快捷键。

开启：

1. 设置页「脚本执行」点「允许」（或在侧栏开启目标模式），在浏览器弹窗中允许。
2. 点随后出现的「打开扩展详情」（设置页或侧栏提示中），打开「允许用户脚本」（Chrome 138+）；Chrome 135–137 改为打开扩展管理页右上角的「开发者模式」。
3. 回到设置页，状态显示「已开启」后，新的一轮模型请求才会提供该工具。

批准：

- 助手请求运行脚本时任务暂停，侧栏显示理由、目标网站、运行环境（隔离环境 USER_SCRIPT，或可访问网页变量的 MAIN）和完整代码。
- 「允许一次」只运行这段代码一次，下一次脚本需重新批准；「拒绝」不运行，助手收到拒绝结果后改用其他方法。
- 「本任务内允许」运行这段代码，并让本任务之后在同一标签页、同一网站上的脚本自动运行；每段脚本的完整代码仍记在对话的工具调用里（折叠显示）。侧栏显示「本任务脚本已自动批准 · 撤销」，点「撤销」后恢复逐次批准。换到其他网站或其他标签页、结束或清空任务、在设置页收回脚本权限都会取消该授权；停止、我来操作和补充指令不会取消。
- 批准前页面已跳转、刷新或切换标签时，脚本不运行，助手重新读取页面。点停止、我来操作、发送补充指令或页面导航都会作废待批准的脚本。

限制：

- 需 Chrome 135 或更高版本；Edge 等其他浏览器取决于其 userScripts 支持。未开启时助手看不到脚本工具；开启后又被关闭时，任务暂停并说明要打开什么。
- 脚本以你的登录状态在网页中运行，可读取和修改页面、发起请求；返回值（最多 4000 字符）会发送至你配置的模型服务。只批准你看懂的代码。
- 只在顶层框架运行，30 秒未返回记为结果未知且不会重跑；脚本的副作用不会自动撤销。
- 仍做不到：封闭式 Shadow DOM、跨源 iframe 内容、画布里的文字（可用[看图](#限制)截图查看）、纯 CSS `:hover`、只接受真实点击的网站。复杂编辑器（如 ProseMirror、Monaco）和基于指针事件的拖拽库未验证。

## 限制

- 页面读取每次最多 16000 字符正文、120 个控件、40 个区域；没读到不代表不存在。
- 同源 iframe 只读取一层（最多 10 个），与主页面共用上述上限；跨源表单授权与限制见[跨源表单](#跨源表单)；嵌套或仍在加载的 iframe 不读取。
- 看图截图、按截图位置点击和真实鼠标输入（下面三条）须在设置中开启「真实输入与截图」（默认关闭）。关闭时模型看不到这些工具，只能就附图再提问；点击到不了目标时回执 `REAL_INPUT_DISABLED`（未发送）并提示可在设置中开启。
- 开启后每次使用前，侧栏显示批准卡片：要做什么（截图可见区域、截图某元素、按截图坐标点击、真实点击/悬停某元素）、哪个网站，并提示浏览器会显示调试提示条。「允许一次」只执行这一次；「本任务内允许」让本任务在同一标签页、同一网站上之后的使用不再询问（侧栏显示撤销入口，换网站、结束任务或关闭设置即失效）；「拒绝」不执行，助手改用其他方法。没有跨任务的「始终允许」。
- 看图：页面文字读不到的图片、画布、图表或布局，助手可截取任务标签页的可见区域或某个元素来看（标签页不必在前台；会显示同样的调试提示条）。截图前用黑块遮盖密码、验证码、卡号等敏感字段和读不到内容的嵌入网页（授权敏感字段后只遮盖文件选择框），遮盖失败就不截图；封闭 Shadow DOM 里的内容不在遮盖范围内。能看图的模型只在下一轮看到这张截图（同时最多 3 张），之后不再发送，所以助手应把看到的要点记进进度笔记；不能看图的模型改为收到识别模型的文字（计一轮，失败自动重试 2 次，可能有误，金额、编号以页面文字为准）。不能截整页长图。
- 按截图位置点击：能看图的模型看过可见区域截图后，可对快照里没有的目标（图片、画布、嵌入内容中的位置）按截图坐标发一次真实鼠标点击（`click_point`，回执标明 `input: cdp`）。只用最新一张可见区域截图、同一页面、60 秒内有效，页面滚动或窗口大小变了就不点，每张截图只点一次，之后重新读取页面核对；被遮盖的黑块区域模型看不到。不能看图的模型没有这个工具。
- 图片/画布内部只能按截图位置点击（见上）；不支持嵌套、重定向或同 URL 多 iframe、Shadow DOM、浏览器原生 confirm/alert、复杂富文本、拖拽、长按，其中一部分可开启[脚本执行](#脚本执行)处理。
- 不支持 IME 组合输入、多标签并行操作（同一时刻只操作一个标签页）、跨浏览器重启恢复任务。
- 点击和悬停默认用合成事件；点在嵌入的其他文档上时，只有已「本任务内允许」才自动改用真实鼠标输入，否则不点击并提示助手改用需批准的真实点击。合成点击发出后不会自动再点（网页可能几秒后才有反应）；只改样式的选中（如图片宫格选中某格）回执为「目标外观已变化」，助手不会再点把它取消；助手先看截图或重新读取页面确认没有效果后，才可对同一目标要求真实鼠标点击/悬停一次（`trusted:true`，不先发合成事件）。回执标明 `input: synthetic` 或 `cdp`。第一次使用时浏览器会显示「正在调试此浏览器」提示条，任务完成、暂停、停止或结束后消失；点提示条上的「取消」后本任务不再使用；开发者工具占用标签页时不可用。按键、双击、右键、滚轮仍是合成事件，浏览器快捷键和原生右键菜单不会触发。
- 没有交互线索（角色、onclick、tabindex、pointer 样式）的自定义控件可能识别不到。
- 网络错误、超时、429/5xx 最多额外重试 2 次；连续 3 次同类操作无变化会暂停（目标模式 6 次）。

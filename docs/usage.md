# Page Agent Lite 使用指南

轻量 Chrome / Edge Manifest V3 扩展：在浏览器侧边栏输入目标，助手读取当前网页，通过模型决定操作，逐步执行并检查页面。使用浏览器现有登录状态，无需 Python 服务、构建或运行时 npm 依赖。

## 安装与更新

1. 克隆[本仓库](https://github.com/sansan-mei/page-agent-lite)，使用新版 Chrome / Edge。
2. 打开 chrome://extensions 或 edge://extensions，开启开发者模式。
3. 选择「加载已解压的扩展程序」，加载仓库里的 **extension/**。
4. 在普通 HTTP/HTTPS 网页点击扩展图标，授予当前站点临时访问并打开侧边栏。

manifest 最低版本为 120；浏览器还须支持 local 存储访问隔离 API，缺少时会拒绝初始化，请升级。更新源码后重新加载扩展并刷新已有网页。本次增加 sidePanel 和 alarms 权限，浏览器可能要求重新启用扩展。已有 API 配置、助手设置及文章记录保留；若旧会话仍存在，会把目标迁移成暂停任务，点击继续即可。不交付 ZIP 或 Release。

## 配置

若扩展错误页出现 `importScripts ... core.js failed to load`，说明扩展自身脚本未加载，不是网站授权或 API 密钥问题。先关闭侧边栏，在扩展管理页点重新加载，刷新目标网页后再打开。确认加载的文件夹为完整 `extension/`，并包含 core.js、prompts.js、backend.js、task-store.js、site-memory.js、browser-tools.js、runtime.js；不要只更新 background.js。若仍失败，重启浏览器并查看清除历史错误后的最新提示。不要通过开放全站权限来解决本地依赖加载失败。

右键扩展图标选择「选项」，或点击侧边栏「设置」：

- API 基础地址：例如 https://api.openai.com/v1，不要追加 /chat/completions。支持 HTTPS 或 localhost / 127.0.0.1 / [::1] 的 HTTP。
- 模型与密钥：填写服务商支持的模型 ID；本机无鉴权服务可留空密钥。仅支持非流式 OpenAI Chat Completions。
- 默认回复语言、执行轮数上限、模型上下文窗口与压缩阈值。**默认 50 轮，0 表示不限**；已有配置保留原值。

点击授权并保存；API 与网页站点授权分开。保存不代表连接已验证。密钥仅由扩展后台使用，不返回内容脚本。

### 网页访问授权

侧边栏直接提供「授权当前网站」和「授权全部网页」按钮；设置页也保留「授权所有网站」。后者在浏览器确认后一次授予普通 HTTP/HTTPS 网站访问，无需逐站重复操作；扩展仍只在你开始或继续任务时操作绑定网页。全站授权不等于跨站任务支持，也不会自动操作未启动任务的网页。浏览器内部页、扩展商店等仍受保护。

本次增加 tabs 权限，用于读取当前标签页标题和地址、确定授权目标；网站内容访问仍通过 activeTab 或可选主机权限授予。更新后请在扩展管理页重新加载并确认新增权限。可在浏览器扩展详情的「网站访问权限」中调整或撤回授权。

## 开始任务

在侧边栏输入目标，例如“读取这页题目并填写选项”或“帮我整理这些页面”。当前支持顶层 DOM 文字读取、文本填写、原生勾选、下拉选择、滚动、自动按钮和链接点击。

侧边栏以任务目标和最近消息为主，按时间从上到下排列。模型动作以工具调用卡片展示，展开可查看请求参数及返回结果；执行中、等待核对、已核实、结果未知与错误分开显示。参数是经校验的动作 JSON，返回结果是扩展工具回执，不是模型 API 的原始 HTTP 请求/响应；不展示 API 密钥或授权头。旧记录没有完整参数时明确提示，不补造。已返回和本地核对不等于网站服务器保存或任务完成。底部固定输入框及一行状态/轮数，Enter 发送，Shift + Enter 换行；中文输入法选词回车不会发送。运行时显示「停止」，暂停或停止后显示「继续任务」。顶部保留「历史记录」「新对话」「设置」。点击「历史记录」进入当前对话的只读记录页，可查看任务 ID、观察/操作/核对计数、上下文用量、工具结果、核对证据及「运行详情」；点击「返回对话」回到消息区。此页只展示当前对话保留的数据，不是以往对话列表；其中工具结果和完整状态记录仍是最新在上。详情不是原始 API 请求/响应或完整轨迹，消息基于任务已有的滚动记录，不等于跨任务聊天历史。查看旧消息时新进度不会强制滚动，停留底部时跟随新消息。填写、勾选、选择与点击均直接自动执行，不再提供独立开关，旧开关值不再生效。自动点击包括提交、删除等按钮；可随时停止，已发出的操作不会自动撤销。模型答案可能有误，需按实际页面核对。

- **停止**：取消后台模型请求，丢弃迟到结果；已发出的网页操作不会撤销。
- **继续任务**：重新读取当前页。耗尽预算或已完成后继续，会开启新预算。
- **发送**：未结束的任务追加补充指令，保留原目标、任务 ID、操作进度和轮数；重新读取页面后继续。发送成功清空输入框，失败或提交期间新写的草稿保留。
- **新对话**（顶部历史记录旁）：结束当前任务、清空旧草稿并返回空白对话；下一次发送创建新任务。发送新目标时将旧对话归档，历史页按标题、更新时间和状态列出，点击只读查看；查看历史不会恢复任务或发送给模型。历史只限当前标签页与网站，关闭标签页或浏览器后不保留。模型已完成或手动结束后，下次发送创建新任务。停止、暂停、失败、待确认都不算完结，仍接着原任务。
- **清空当前对话记录**（历史记录页底部）：停止并删除当前标签页任务及临时记忆；已归档的其他对话保留。归档对话暂不提供逐条删除，可关闭标签页清除该标签页全部会话记录。

关闭侧边栏不会停止任务。同站点刷新/翻页后，后台继续；翻页链接直接自动执行。跨站跳转暂停，回到原站点后可继续。后台休眠后由浏览器事件和 alarm 恢复，可能有延迟；执行结果不确定时暂停检查，不重放操作。

任务按标签页保存在 storage.session；浏览器会话结束、扩展重载或更新等可能清除，**任务与临时记忆不跨浏览器重启；网站长期记忆独立保留**。切换标签页只切换显示，原任务仍绑定原页；关闭标签页删除任务。

点击后回执丢失不一定是操作失败：可能是页面跳转销毁了旧连接。后台会先等待新页或重连读取，不重复点击。模型仍有工作但确实受阻时应返回暂停，而不是标为完成；已打开正确页面后可点继续。

## 任务上下文

在设置页填写模型实际支持的上下文窗口（默认 100000 token，支持 8192～262144）和压缩阈值（默认 80%，可设 50%～95%）。系统预留 2000 token 输出空间；普通执行不再按操作条数或 8000 字符提前压缩。设置对新任务或点击继续后的任务生效，不会自动识别模型窗口，已有自定义窗口保留。

优先使用接口返回的输入 token 用量，加上后续内容变化的估算；未返回 usage 时采用 ASCII/非 ASCII 字符估算，非精确 tokenizer。缓存 token 仍占上下文窗口，侧栏显示上次输入量及服务商报告的缓存命中量。历史尽量追加，当前页面和状态放最后；本插件不设置服务商专用缓存参数，也不保证缓存命中。

接近预算才调用模型把旧结果整理为「已完成及证据、待完成、关键事实与纠正、失败方法、未确定操作」，保留至少最近 6 条完整结果，并按输入预算 20% 扩展近期保留范围。侧栏可在「历史记录」页的「运行详情」中展开「当前任务摘要」查看。原目标、用户补充和当前状态独立保留；补充指令达到 12000 字符上限明确拒绝追加。

压缩成功后，旧结果归档在当前任务中，模型可用 history_read 分页读取原文；归档最多 100 万字符，满后暂停且保留原记录。归档随当前任务清空删除；任务被替换时随旧对话保留为只读历史，不加入新任务模型上下文，也不是长期记忆。摘要输入对超过 4000 字符的单条结果使用首尾摘录，遗漏部分可从归档恢复。

摘要请求计入轮数，失败保留原记录并暂停。压缩后若仍超阈值会暂停，避免反复支付无效摘要费用。摘要可能遗漏细节，不代表任务已完成。执行日志仍最多 40 项；归档仅覆盖压缩掉的工具结果，并非完整聊天记录。

## 临时记忆

模型可以自行调用工具保存、读取、更新、删除或清空临时笔记，例如用户更正的答案、题目对应关系和需要接着处理的信息。每轮默认只提供记忆名称目录，由模型决定是否读取正文、何时清理；补充指令带持续的记忆审查提醒，提示模型在下一次网页操作前保存有用纠正；成功写笔记后清除提醒。这仍由模型判断，不是自动保存全部聊天，也不保证每条更正都会被模型保存。

记忆按标签页和网站隔离，可跨任务和同站翻页使用；模型完成或手动结束任务不会自动清除。设置页选择目标网页后展开「临时记忆」可查看和手动清空；手动清空会使进行中的旧回复失效并暂停，点击继续重新读取。「清空任务」、关闭标签页或浏览器会话清除时，相关记忆也清除。每站最多 12 条，总序列化长度最多 8000 字符，单条最多 2000 字符；每个标签页最多 10 个站点。

记忆属于历史资料，当前用户纠正优先。填写、选择后会核对本地字段实际状态，不能据此保证答案正确或网站提交评分成功。

## 网站长期记忆

设置页选择目标网页后展开「网站长期记忆」即可查看、编辑、删除、清空或导出当前网站的笔记。数据保存在扩展自己的 IndexedDB，同一网站跨标签页和浏览器重启可用，不随清空任务、关标签页或扩展重载删除。卸载扩展、清除扩展数据或浏览器清理存储可能丢失，请用 JSON 导出备份；暂不支持导入或同步。

按完整 origin（协议 + 主机 + 端口）隔离：子域名、HTTP/HTTPS、不同端口不共享。一个网站的不同账号会共享笔记，切换账号时需检查适用性。每站最多 32 条、总序列化 64000 字符，单条 2000 字符。模型默认只看到名称目录，可自行决定用 site_memory_read/write/delete/clear 读取或维护，不自动持久化全部对话，也不自动迁移临时记忆。

长期笔记用于稳定偏好、验证过的网站操作经验和可复用事实；不应记录密钥、密码、敏感身份信息或临时元素 ID。笔记是历史资料，用户当前指令和当前页面证据优先；这些内容按需发送至已配置模型，本机数据库不是加密保险箱。

手动修改会让同网站旧请求失效并暂停相关运行任务，继续后重新读取。并发写入按版本校验，冲突需刷新重试，避免旧回复覆盖新笔记。删除笔记也会清理任务摘要及工具读取缓存；用户原始指令和执行记录不因此删除。

## 旧文章工具

独立文章面板与专属站点配置已移除，更新后取消旧站点自动注入。历史文章记录仍在本机存储，当前界面不再提供恢复、修改或撤销入口；刷新网页可移除此前已注入的临时面板。网页读取与内容整理使用侧栏通用任务。

## 当前限制与数据

已支持通用预期条件、等待和只读验证：字段值/勾选状态、区域文本/可见性/存在性及 URL。操作后可等待反馈，侧边栏显示预期和实际证据；等待轮询不消耗额外模型轮数。模型给出完成条件时必须核实，未提供时明确标为“模型报告完成”，不代表代码已验证整个任务。

等待默认 10 秒，最多 30 秒。点击后的元素核对若因证据不足返回未知，超时后最多两次重新读页规划，并阻止在同一文档重发结果未明的原点击；明确不匹配、完成条件未满足或恢复耗尽仍暂停。标签页仍在加载资源时，会先只读检查当前页面；地址一致、没有待跳转地址且 DOM 已就绪即可继续核对，不必等待所有资源完成。页面替换后只对唯一语义匹配进行只读核对，歧义或截断返回未知。确认弹窗控件优先进入快照，与背景同名按钮按分组区分；操作核对显示目标及 TARGET_MISSING、AMBIGUOUS_TARGET 等具体原因。保存回执丢失后不重复保存；worker 恢复保留原期限。

- 顶层 DOM 最多读取 16000 字符正文、120 个交互元素；超出截断，尚无按需分区读取。除原生控件外，也识别带交互角色、onclick、非负 tabindex 或 pointer 鼠标样式边界的自定义控件；没有这些线索的控件仍可能遗漏，不能仅凭计数或位置猜测点赞按钮。
- 暂不支持图片/画布、iframe、Shadow DOM、富文本控件、多标签页协作或跨站任务。
- 操作结果区分派发、UI 状态及页面反馈。无预期的点击仍只报告变化或未知，不保证网站已保存。连续三次同类操作无变化会暂停。
- 临时网络、25 秒超时、429/5xx 最多额外重试两次；尚无完整自主规划、跨会话任务恢复或技能学习。
- 浏览器内部页、商店等受保护页面无法操作；部分网站拒绝程序事件。

任务会将目标、最近操作、页面文字及普通表单内容发送给所配模型。密码、文件、隐藏字段及扩展 UI 被排除，但不保证识别所有隐私。无遥测或模型生成脚本执行。任务仅用白名单工具与当前快照 ID，网页不是系统指令。

响应体最多 64 KiB，模型文本最多 12000 字符；后台可信任务请求最多 100 万字符（网页发起仍限 48000 字符），文章输入最多 12000 字符，选区最多 6000 字符。文章记录每页最多 30 条 / 120 KB，总计 20 页 / 240 KB，最多启用 20 个站点。本机存储不是加密保险箱，模型数据政策由服务商决定。

## 全局长期记忆

在设置页「网站与记忆管理」展开「全局长期记忆」，可查看全部笔记正文，点击编辑后保存；也支持新增、删除、清空及导出 JSON，不需要选择网页。网站长期记忆继续按所选网页的完整 origin 管理。全局适合“以后统一用中文表格”等跨站偏好，本站流程仍放网站笔记；没有云同步。

修改全局笔记会取消各网站旧请求并暂停相关任务，返回侧栏继续。保存失败保留编辑草稿；版本冲突时先刷新，再核对新正文后保存。全局与网站各最多 32 条/64000 序列化字符，单条 2000 字符。记忆只作参考，不保证模型每次都会正确记录或使用。

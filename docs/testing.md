```powershell
Get-ChildItem extension/*.js | ForEach-Object { node --check $_.FullName }

```

## 浏览器烟雾检查

CI 安装 Playwright / Chromium，通过 xvfb 运行 `node scripts/browser-smoke.cjs`。临时复制扩展，仅临时 manifest 注入 loopback 权限，生产 manifest 不预授权站点，模型使用本机 stub。

本机可显式运行 `node scripts/browser-smoke.cjs --local`，无窗口模式且允许未提交源码；需安装 Playwright 和兼容浏览器。可用 PAGE_AGENT_CHROMIUM 指定测试浏览器，使用临时 profile，不碰用户已有 profile。

当前覆盖侧边栏扩展文档发起任务、默认自动填写与点击、跨文档翻页、ID/预算保留；设置页检查默认 100000 token 与无自动执行开关、无文章工具入口。文章面板已退役，不再包含于当前浏览器烟雾链路，兼容源码仍有模拟测试。侧边栏文档在测试标签页打开，不验证原生侧栏位置或工具栏手势。报告和截图在 tests/browser-output/，不提交。

通用 V1 当前检查：74 项模拟测试通过；Edge 158 无窗口真实扩展检查通过 25 个流程断言、28 次 stub 请求。增加字段 DOM 替换、3 秒异步筛选、限定区域保存反馈、保存回执丢失但请求只发一次、显式 wait 及不满足完成条件时暂停。通过 CDP 在条件等待阶段真实停止 worker，验证任务 ID 和 deadline 保留，完成后模型轮数仍为 2。

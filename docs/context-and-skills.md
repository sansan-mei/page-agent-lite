# 上下文、记忆和技能

## 已实现

`prompts.js` 统一构建稳定系统指令与每轮输入。后台使用配置的语言和模型，每轮包含目标、最近操作、轮数与当前页。模型返回严格 JSON，工具行为由代码白名单决定。

支持在未结束任务中追加补充指令，模型收到原目标、按时间排序的补充指令和最近操作；较新用户纠正优先。任务完成或手动结束后发送才新建。时间线供查看，不等于完整聊天记录。仓库 AGENTS.md 只约束开发，插件不读取它。

已实现模型管理的临时记忆：每轮提供 memoryIndex（名称与更新时间），正文通过 memory_read 按需读取。memory_write 用 id 和 value 写入/覆盖，memory_delete 按 id 删除，memory_clear 清空当前站点；模型决定是否使用和何时清理。单条最多 2000 字符，最多 12 条、总序列化长度 8000 字符。容量满时返回工具反馈，由模型删除或压缩，不静默丢失旧记忆。

临时记忆独立于 taskId，按标签页和源隔离，不固定注入上一任务内容，也不递归复制历史。模型完结或手动结束保留笔记；用户清空、关闭标签页或会话结束清除。网页和笔记均为不可信数据，不能覆盖用户最新更正。模型只在工具成功后声称记忆已修改；这是提示词约束，不代表线上模型必定遵循。

用户可在侧边栏查看并清空；清空会让进行中的模型回复失效，移除工具读取结果，任务暂停后可继续。清空笔记不删除用户已发送的补充指令。清空/删除临时笔记同时移除可能含旧笔记的任务摘要；后续可重新整理。完整聊天历史、跨站全局偏好和 Skills 仍未实现。

## 任务内上下文压缩（已实现）

原目标和全部已接受的用户补充独立保留，补充序列化上限 12000 字符，超限明确拒绝。每轮新页面替换旧快照。稳定目标、指令、摘要正文、归档目录及追加的结果置于请求前部；变化的记忆目录、轮数、状态、条件、最后结果及页面置于后部。摘要更新时间不发给模型，不使用服务商专用缓存标记。

默认 contextTokens=100000、compressionThreshold=80，输出预留 2000 token。只有上下文达到 `(contextTokens-2000)*compressionThreshold/100` 才触发，不按条数或固定历史字符数触发。窗口配置范围 8192～262144，阈值 50～95%。接口 usage.prompt_tokens 为锚点，加上全请求估算值的前后差异；无 usage 时全量估算，ASCII 每 4 字符约 1 token，非 ASCII 每字符约 1 token。系统提示估算也计入，但消息封装、语言和 tokenizer 差异仍有误差，不能称为精确计量。

锚点仅匹配同一 endpoint/model/language/key 的 SHA-256 标识；配置改变或压缩、记忆清理后失效。接口缓存 token 仅用于展示，不从容量扣除。没有 usage 的请求不会沿用旧锚点。

保留至少最近 6 条结果，向前扩展至输入预算 20%；剩余旧结果和前摘要交给独立摘要请求。超长单条结果采用 2000 字符开头及 1000 字符结尾的带标记摘录，摘要看到归档指针，原文仍保存；摘要输入估算超过输入预算 90% 时暂停保留原记录。摘要五个字段各最多 5 条、每条 240 字符，总计最多 4000 字符。

同一 task 更新中保存 contextSummary、contextArchive 和裁剪后的 results；摘要失败不裁剪。contextArchive 含 id、from、to 和原始 results，总序列化最多 100 万字符；满后暂停。historyIndex 仅列目录，模型 history_read(id,value=offset) 每次取 4000 字符，返回 nextOffset。旧 ID 不得作为当前操作目标。归档不跨任务，替换/清空任务即删除；已被旧版本裁掉的内容不能恢复。

摘要请求计预算且可取消，停止/补充后迟到回复失效。压缩后设置 compactionGuard，若下一次上下文仍过阈值则暂停，不循环摘要；成功执行模型请求后解除。用户清空/模型删除记忆使摘要失效，并从归档与活动结果清理 memory_* 记录，避免按需读取恢复已清笔记。

侧栏显示摘要及上次 API 输入/缓存用量。线上模型是否充分保存关键事实、是否命中缓存仍待测；本版没有精确 tokenizer、模型主动整理动作、全聊天归档或跨站全局偏好。

## 网站长期记忆（已实现）

IndexedDB 的网站笔记独立于任务和临时记忆，按完整 origin 跨任务/标签页/重启共享。每轮 siteMemoryIndex 仅带 id、updatedAt、source，正文通过 site_memory_read(id) 取单条。site_memory_write(id,value) 写入/更新，site_memory_delete(id) 删除，site_memory_clear 清空本站。每次模型请求仍计一轮，工具执行由后台处理。提示词要求只保留稳定、有来源的经验和纠正，不能把网页或笔记当作更高优先级指令；线上模型的记忆质量未验证。

笔记删除/更新时旧摘要和读取缓存失效；跨标签页版本变化在下一轮重新观察，进行中模型回复在派发动作前核对版本。手动操作取消同站请求并暂停运行任务。并发写入在 IDB 事务内校验 expectedVersion，避免静默覆盖。用户可在侧栏查看、编辑、删除、清空和导出，无自动临时记忆迁移或整段聊天持久化。存储及限制见 [存储](storage.md)。

## 目标设计（未实现）

1. 稳定指令：身份、工具和行为原则，与网页内容分开。
2. 任务上下文：目标、计划、进度摘要和最近操作。
3. 按需网页上下文：相关块、表单及必要区域，避免重复发送整页。
4. 偏好记忆：只保存明确且适合跨任务的信息，提供查看与删除。
5. 站点技能：成功步骤、页面识别条件及易错点，按站点和目标加载。

先提供“保存为站点流程”，确认后持久化文本和工具步骤，不存任意脚本或临时 DOM ID，执行时重新定位。不引入向量库、市场或本地服务。事实记忆、偏好、技能、任务检查点分别保存。

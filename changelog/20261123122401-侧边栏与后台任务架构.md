# 侧边栏与后台任务架构

- 记录时间：2026-11-23 12:24:01 +08:00（Asia/Singapore）
- 类型：重构 / 新增 / 文档

## 变更说明

- 将对话任务从网页移至浏览器侧边栏与后台任务运行器，内容脚本仅提供读取和白名单操作。
- 增加 taskId、运行代次、结构化状态、执行阶段、时间线及每步检查点。默认 50 轮不变，翻页保留预算。
- 后台事件和 alarm 调度恢复；停止取消模型请求并拒绝迟到结果。恢复到执行结果不确定阶段时暂停，不重放副作用。
- 增加快照稳定性等待、过期目标重新规划、临时 API 最多额外重试两次、连续三次相同操作无变化暂停。
- 保留独立文章工具；设置与文章记录不迁移丢弃。旧会话目标迁移为暂停任务，旧站点脚本注册升级。
- README 改为使用入口，新增六份模块文档，更新 AGENTS 和 roadmap。历史 changelog 保留，不将旧架构说明当作当前设计。

## 涉及文件

- `extension/sidepanel.*`：独立对话与任务 UI。
- `extension/runtime.js`、`task-store.js`、`prompts.js`：运行器、检查点与上下文。
- `extension/browser-tools.js`、`content.js`：后台适配与页面工具协议。
- `extension/background.js`、`backend.js`、`manifest.json`：入口、取消、站点脚本升级及新增 sidePanel/alarms 权限。
- `extension/article-tools.js`、`options.html`：保留文章工具并更新说明。
- `tests/`、`scripts/browser-smoke.cjs`：按新边界调整测试，支持显式本机无窗口烟雾检查。
- `README.md`、`AGENTS.md`、`ROADMAP.md`、`docs/`：使用与开发文档。

## 限制与后续

- 关闭侧栏不停止任务；会话存储不保证浏览器重启或扩展重载后的保留。
- 所有点击仍需确认。图片、iframe、Shadow DOM、跨站任务、长期记忆、站点技能及完整自主计划未实现。
- 当前页可观察变化不等于网站操作语义成功；下一阶段补结果断言与完整浏览器故障恢复验证。
- 本机旧 Chromium 130 无所需存储隔离 API，系统 Chrome 不接受本测试的解压加载路径；最终成功验证使用 Edge，不声称各浏览器版本全部验证。

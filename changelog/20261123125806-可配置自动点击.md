# 可配置自动点击

- 记录时间：2026-11-23 12:58:06 +08:00（Asia/Singapore）
- 类型：新增

## 变更说明

- 独立设置页增加自动点击开关，开启后按钮、链接及翻页直接执行，无需逐次确认；默认关闭，旧配置兼容。
- 与自动填写分开控制；关闭自动填写时，填写仍需确认。
- 新任务或显式继续任务加载新设置，旧待确认动作重新读取规划；侧边栏显示当前点击模式。
- 模型指令改为由运行器应用用户设置，不要求模型反复请求确认；停止和过期快照检查保留。

## 涉及文件

- `extension/backend.js`、`background.js`、`runtime.js`、`prompts.js`：配置、校验和执行策略。
- `extension/options.*`、`sidepanel.*`：开关、反馈与操作说明。
- `tests/backend.test.js`、`runtime.test.js`、`scripts/browser-smoke.cjs`：旧配置、模式独立、继续后生效和实际自动翻页。
- README、AGENTS、roadmap 及相关模块文档同步当前策略。

## 验证

- 40 项模拟测试、扩展 JS 语法检查及差异检查通过。
- Edge 本机 stub 烟雾检查包含设置页开启自动点击、填写后无需批准命令直接翻页并完成。未使用线上模型。

## 限制与后续

自动点击适用于模型提出的所有按钮点击，不区分提交、删除或一般导航；设置页明确说明。已发出的网页操作不能通过停止撤销。跨站任务边界不变。

# 任务站点范围管理与权限撤销门禁

- 记录时间：2026-11-23 21:34:38 +08:00（Asia/Singapore）
- 类型：新增

## 变更说明

- 侧栏任务范围面板支持最多 16 个完整 HTTP/HTTPS origin；用户手势先申请主机权限，再经可信后台修改当前 taskId/scopeRevision。浏览器全站授权不自动增加任务范围，取消授权不修改集合，转任务后的迟到授权不能附到新任务。
- 原始/普通检查点写入不能伪造授权集合、初始来源或成员。专用 changeOrigins 使用 pending/root/binding 修订发布；写入中断启动对账到暂停态。
- 有效修改取消旧请求与调度、旋转 token 并暂停，清摘要/用量锚点/计划缓存，保留累计轮数和未确定 phase/pending/check/原 deadline。
- 当前来源移出范围后不能继续、补充或观察；浏览器主机权限撤销触发复核暂停，live 在异步权限查询后再次核对任务/token/取消信号。重新授权后原期限只读核对，不重放。
- 当前仍只支持起始 origin 执行；本次新增范围管理与撤销门禁，未放开跨 origin 导航或历史/笔记交接，界面与文档明确边界。

- tests/sidepanel.test.js、background.test.js、runtime.test.js、task-store.test.js、scripts/browser-smoke.cjs：授权顺序/拒绝/迟到、来源隔离、故障与浏览器回归。
- README.md、ROADMAP.md、docs/storage.md、agent-runtime.md、architecture.md、task-scope-v3.md、testing.md：操作与真实实现状态。

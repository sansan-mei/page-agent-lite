# 虚拟鼠标反馈与悬停

- 记录时间：2026-11-23 17:38:27 +08:00（Asia/Singapore）
- 类型：新增 / 修复

## 变更说明

- 增加页面内蓝色虚拟指针、目标边框及点击圆环。动画与实际操作并行，不等待动画，不移动系统鼠标；默认约 900 毫秒自动隐藏，连续操作可从上次位置移动。
- 填写、选择、勾选、点击及 hover 使用本机显示层；显示层不截获鼠标、不进入页面文本或目标列表，也不影响隐藏元素覆盖判断。后者在浏览器回归中发现并修正。
- 新增 hover 白名单动作，沿用当前快照 id、目标签名、可见性、禁用和点击命中校验；派发进入/移动合成事件，不触发点击。随后重新观察或按 expected 核对。
- 停止、手动结束、运行器非活动状态及页面生命周期/滚动/尺寸变化清理显示层；遵循减少动态效果偏好。
- 视觉反馈无额外模型请求或快照内容；hover 的工具说明、动作记录及后续观察可能增加 token/轮次。

## 涉及文件

- `extension/page-pointer.js`：隔离样式显示层及动画、清理。
- `extension/core.js`、`content.js`：视觉反馈、hover 及可信后台清理接口，排除扩展 UI 的隐藏覆盖标记。
- `extension/browser-tools.js`、`backend.js`：随页面工具注入显示模块；浏览器清理消息适配。
- `extension/runtime.js`、`prompts.js`：停止/结束/非活动清理，hover 说明。
- `tests/agent.test.js`、`tests/page-tools.test.js`：悬停菜单无点击、失效/未知目标、清理消息来源回归。
- `scripts/page-pointer-smoke.cjs`：本机真实浏览器显示/悬停回归。
- `README.md`、`ROADMAP.md`、`docs/browser-tools.md`、`docs/architecture.md`：使用、边界及当前实现说明。

## 限制与后续

- 合成 hover 不保证触发纯 CSS :hover 或依赖 isTrusted 的控件；未实现拖拽、右键、双击或系统鼠标控制。
- 显示层在普通 DOM 层级，不能保证盖住浏览器 top layer 中的原生模态框/弹出层；视觉反馈不作为操作成功证据。
- 不新增权限、依赖、打包产物或任务持久状态。原有未提交修改保留。

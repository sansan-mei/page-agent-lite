# 侧栏对话布局精简

- 记录时间：2026-11-23 17:12:49 +08:00（Asia/Singapore）
- 类型：界面调整

## 变更说明

- 参考 Alibaba Page Agent 扩展侧栏的小标题栏、消息区与底部输入布局：https://github.com/alibaba/page-agent/blob/main/packages/extension/src/entrypoints/sidepanel/App.tsx 。独立编写原生 HTML/CSS/JS 实现，不引入其框架、组件或运行能力。
- 去掉默认展开的任务仪表信息与重复结果卡；目标作为用户消息展示，最近消息按时间从上到下排列，已成功的重复工具结果留在详情中。
- 任务 ID、阶段计数、token、工具原始结果、核对证据、摘要和完整状态日志收进默认折叠的「运行详情」。详情里的工具结果与日志仍是最新在上。
- 输入区固定底部，状态和轮数合为一行；运行时显示停止，暂停等状态显示继续。结束与清空收进右上角更多菜单；设置与当前网站授权入口保留。
- 支持 Enter 发送、Shift + Enter 换行，并阻止中文输入法选词回车误发。运行中仍支持补充指令，成功清空草稿，失败保留。
- 在底部跟随新消息，用户查看旧消息时保持阅读位置；空闲、运行与暂停使用相同简洁布局。修正旧页脚仍提示「开启自动点击」的过时文案。

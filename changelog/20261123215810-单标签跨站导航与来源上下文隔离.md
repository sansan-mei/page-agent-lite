# 单标签跨已授权来源导航与上下文隔离

- 记录时间：2026-11-23 21:58:10 +08:00（Asia/Singapore）
- 类型：新增

## 变更说明

- navigate 同时核对用户任务 origin 集合、源/目标浏览器主机权限及当前快照；后台最终派发前再核对来源和取消信号。跨来源只绑定 URL 条件，不把旧 DOM 条件放到新页面核对。
- 浏览器 URL 变化/主文档加载取消旧请求。单标签 A→B→A 保留 taskId、initialOrigin、累计轮数/指标、用户目标/补充；每次来源变更发布新 token/范围版本，并重新观察。
- 旧来源结果/摘要/归档先保存为独立 session 只读历史，目标根从空结果/计划/摘要/笔记缓存重建；模型不能 history_read 这些来源分区，返回旧站点也不恢复旧正文。只恢复返回来源的历史未知点击防重放约束，不给其他来源模型提供该约束的旧标签。
- 未授权来源、旧 DOM 条件、无 URL 证据的未知执行或未预期重定向暂停并保留原期限，不读取新来源正文或重放。浏览器层与内容端 expectedOrigin 防止观察/核对/重连读取错源。
- 切换意图/旧来源归档/新根/归属索引分阶段提交，中断启动只读对账到暂停态；回滚移除临时分段。来源历史容量不足保留原根并暂停，不循环重试或裁剪。历史按当前 origin 和任务授权过滤，清空当前任务删除其来源分区。
- 修复 URL 变化取消造成同源普通链接跳转停留 executing 的兼容回归：记录 unknown 和防重放信息后新观察，不把导航当业务成功。只读历史快照不被其他 origin 的活动根覆盖。

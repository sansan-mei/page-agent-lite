# 按上下文预算压缩与缓存统计

- 记录时间：2026-11-23 15:25:29 +08:00（Asia/Singapore）
- 类型：调整 / 新增

## 变更说明

- 取消 12 条结果或 8000 字符触发，改为按模型输入容量压缩。设置页新增窗口（默认 32768 token，8192～262144）和阈值（默认 80%，50%～95%），扣除 2000 token 输出预留。
- 优先采用接口 prompt_tokens 加后续内容变化估算；无 usage 时使用字符估算。缓存 token 只用于展示，不从上下文占用扣除。端点/模型/语言/密钥配置散列变化时旧锚点失效。
- 稳定目标、摘要和追加历史放前部，变化的状态和页面放后部；不注入服务商专用缓存参数，不保证命中。
- 后台可信任务输入由 48000 提升到 100 万字符；网页请求维持旧限制。摘要前按预算摘录超长单条结果，保存完整原文供读取。
- 压缩成功后原结果归档在当前任务，模型通过 history_read 以 4000 字符分页恢复；归档 100 万字符上限，达到后暂停保留原记录。近期尾部至少保留 6 条，按输入预算 20% 扩展。
- 压缩后仍超阈值时暂停，避免反复付费整理；清理临时笔记也清理归档中的记忆/恢复记录。摘要失败和迟到结果处理继续保留。
- 侧栏显示 API 输入 token 和可用的缓存命中统计；摘要仍可展开查看。

## 涉及文件

- `extension/prompts.js`、`runtime.js`：预算、估算、用量锚点、归档、读取与压缩保护。
- `extension/backend.js`、`background.js`：可信长请求、usage 归一化、路由配置散列。
- `extension/core.js`：history_read 白名单及参数校验。
- `extension/options.html`、`options.js`、`sidepanel.html`、`sidepanel.js`：配置与用量展示。
- 后台、运行器测试及浏览器 smoke；README、AGENTS、ROADMAP 和模块文档同步。

## 验证

- 90 项模拟测试通过，覆盖低压力不提前压缩、用量锚点和缓存统计、配置失效、归档恢复、稳定前缀、取消、清理和无效压缩保护。
- Edge 158 真实扩展、本机 stub：26 个流程断言、30 次请求通过，长历史按预算压缩后传入下一轮，归档保留。
- 扩展/脚本语法、文档链接及本次涉及文件的差异检查通过。
- 首轮浏览器检查触发 stub 旧 64 KiB 请求体限制；更新测试限制并加摘要输入摘录后重跑通过。

## 限制与后续

- 窗口须手动按服务商实际限制填写；估算不等于精确 tokenizer。未实现自动窗口探测、服务商专用缓存标记或超窗错误自动调参。
- 未验证实际线上缓存命中率、费用收益、自然长任务或摘要质量。浏览器使用预置长历史和模型 stub，不验证原生权限弹窗和侧栏位置。
- 归档限当前任务和浏览器会话，只覆盖压缩结果，不提供完整聊天归档。旧版本已经裁掉的内容无法恢复。

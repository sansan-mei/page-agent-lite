# 支持长正文分段读取

- 记录时间：2026-11-23 19:10:26 +08:00（Asia/Singapore）
- 类型：新增

## 变更说明

- PA1 首个增量：observe 可指定正文偏移，每段 16000 字符，提供范围及下一偏移，后续段不冒充全文覆盖。
- 正文进入下一轮模型上下文；停止/替换与导航后丢弃迟到或旧文档读取，下一轮重新观察再操作。

- tests/core.test.js、runtime.test.js：截断后文本、边界、隐私排除、取消、累计预算和后续模型输入。
- README.md、ROADMAP.md、docs/architecture.md、docs/browser-tools.md、docs/agent-runtime.md、docs/storage.md、docs/page-agent-integration-plan.md：能力与限制。

- 偏移随 DOM 文本变化，不是稳定游标；每次仍提取当前正文，不降低 DOM 扫描成本。
- 不分页控件/区域，不自动全文遍历；PA1 定位、PA2 与批量操作仍待实现。
